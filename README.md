# CraveBite - Fast Food Website (React + Vanilla CSS)

Har component ki apni alag .jsx file aur alag .css file hai.

## Run karne ka tareeqa
npm install
npm run dev

## Structure
src/
  components/
    Navbar/       Navbar.jsx + Navbar.css
    CartSidebar/  CartSidebar.jsx + CartSidebar.css
    Hero/         Hero.jsx + Hero.css
    Features/     Features.jsx + Features.css
    Menu/         Menu.jsx + Menu.css
    ExploreMenu/  ExploreMenu.jsx + ExploreMenu.css  (Categories + MenuCard grid + View All)
    Categories/   Categories.jsx + Categories.css
    MenuCard/     MenuCard.jsx + MenuCard.css
    Deals/        Deals.jsx + Deals.css
    Footer/       Footer.jsx + Footer.css
  App.jsx + App.css
  main.jsx
